## zakura-pasta-curves

### Added

- Added opt-in `ifma` and `x86_64-asm` features providing AVX-512 IFMA batched
  field operations (with runtime CPU detection and scalar fallback) and a
  BMI2/ADX Montgomery multiplier for Pallas and Vesta on x86_64
  ([#273](https://github.com/zakura-core/common/pull/273)).

### Changed

- Sped up GLV multiscalar multiplication via 8-lane batch inversion and
  variable-time arithmetic restricted to public-point paths; secret-scalar
  operations remain constant-time. Outputs are unchanged
  ([#273](https://github.com/zakura-core/common/pull/273)).

## zakura-halo2-proofs

### Changed

- Reduced proving latency through cached proving-key FFT twiddle tables,
  deferred IPA generator folds, evaluator scheduling improvements, and
  variable-time curve operations on public data only. Proof format,
  transcript, and verifier behavior are unchanged
  ([#273](https://github.com/zakura-core/common/pull/273)).
